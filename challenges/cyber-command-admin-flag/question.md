# Cyber Command: admin flag

The challenge instance is available only until completion, and testing is limited to HTTPS. Automated tools may make educated guesses, but blind brute force is not permitted. The application exposes its source code and includes a browser bot. Instance URLs are assigned when the challenge starts and may take up to a minute to become available.

Obtain the supplied application source separately; it is not stored in this repository.

| Question | Points |
| --- | ---: |
| What is the three-digit CWE weakness ID for the vulnerability on `/login`? Multiple IDs are accepted. | 10 |
| What value is set in the bot's cookie for `https://callback/`? | 25 |
| Which page displays unsanitized user input? Submit a path such as `/api/example`. | 10 |
| What value is displayed in `/admin`? | 55 |
