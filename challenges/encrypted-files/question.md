# Encrypted Files

Three files with different encryption formats are supplied: `file1.yaml`, `file2.ppk`, and `file3`. Identify their formats and recover each password using a popular wordlist.

1. What is the password for `file1.yaml`?
2. What is the password for `file2.ppk`?
3. What is the password for `file3`?

The encrypted files are challenge evidence and are not stored in this repository.
