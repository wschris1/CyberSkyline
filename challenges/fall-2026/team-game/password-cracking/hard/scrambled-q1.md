## Prompt

Your team is returning to conduct a password audit for a client to see if they've improved their password security.




The good news? The same password list doesn't work anymore. The maybe bad news? Other team members were able to crack some passwords already, but they forgot to save their documentation on the technique. All they remember is that they were using some hashcat utilities to generate candidate passwords. A few of the passwords they cracked using those methods are included below, maybe this can help to rediscover the password attack they used.




```
berwockyjschachror
inAdminrarwo
!anyonHSV68@F
```




Can you crack all the hashes from this year's audit? Use last year's hashcat potfile as a starting point and reference.

Note: You have been provided more hashes than you will be asked about. That's intentional. Use the full list of hashes when cracking instead of a single hash.
