# Scrambled Python Code

We found a file that does not look encrypted, but the code might be scrambled. Reverse engineer the supplied `collision.pyc` artifact.

Obtain the original file from the challenge platform. The compiled artifact is kept outside this repository.

## Q1 — 10 points

Using `file`, what file type is the downloaded `.pyc` file? The checker is permissive because the command's output can vary.

## Q2 — 50 points

What is the flag found by reverse engineering the source from `collision.pyc`?
