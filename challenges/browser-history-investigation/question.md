# Browser History Investigation

An intern appears to have browsed suspicious sites. A Firefox browser-history export is available, and `sqlite3` is installed on the analysis box.

1. What was the user's first search query?
2. What software did the user likely download?
3. What GitHub repository did the user visit?
4. What support domain did the user visit?
5. What subreddit did the user visit after visiting that support domain?
6. How many minutes elapsed between the first and last activity?
7. What benchmark resource URL did the user visit?
8. How many unique base domains, excluding subdomains, were visited in total?
9. What was the timestamp of the first activity, down to the minute?
10. What was the user's final search query?

Each question is worth 10 points.
