# YARA Secret Hunt

A suspicious project directory was recovered from a compromised repository. Use the supplied `scan.yara` rule to hunt for exposed secrets throughout the codebase.

1. Run `scan.yara` on all files. How many total matches are reported?
2. Which YARA string identifier matches in `database.ini`? Use the format `$<identifier>`.
3. How many different types of sensitive patterns match across all files?
4. Which pattern does not match any file?

Each question is worth 25 points.
