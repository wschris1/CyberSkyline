# Public WordPress Access Log

A nonprofit's web server log was exposed over HTTP. Use the supplied `access (1).log` to identify the web server and WordPress versions, the publicly reachable log directory, the client that fetched the whole log and the transferred byte count, a prior partial fetch, a thumbnail-script request to an external host, and the count of distinct clients sharing one malformed login request.

The log is a supplied challenge artifact and is not stored in this repository.
