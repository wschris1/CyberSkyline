# Device Default Passwords: how to solve

## Approach

Look up each exact model in the manufacturer's manual or support pages. Check the hardware revision and the interface named in the question: the web administrator account, a switch management utility, and printer machine settings may use different credentials. Treat uppercase and lowercase letters as distinct.

## Steps

1. Search the [Zyxel download library](https://download.zyxel.com/) for the P-660HN-51 user guide and find the factory web administrator login section.
2. Find the original FI9821W v1 setup instructions through [Foscam support](https://www.foscam.com/support/). Check whether the factory admin password field has a value. Apply the question's required notation for an empty field.
3. Use [NETGEAR support](https://www.netgear.com/support/) to locate the GS108E-400NAS or its Plus Switch management guide. Read the initial login instructions for the management interface.
4. In [Grandstream's GXP2130 documentation](https://www.grandstream.com/support), distinguish the web administrator account from the phone's user-level account.
5. Find the [Brother HL-L2350DW support guidance](https://support.brother.com/) for the default password used to manage machine settings. Pay attention to the pre-2020 production qualifier, because later units may use a device-specific password.

Cross-check the model and revision before submitting. Keep the actual passwords in the CTF platform, not in this repository.
