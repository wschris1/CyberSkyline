# Remote Desktop Bitmap Cache

Analysts recovered cached bitmap files from a Liber8tion server accessed through Windows Remote Desktop.

1. How many bitmap images are in the binary?
2. At what date and time did the session connect?
3. What is the remote client's IPv4 address?
4. How many images did the adversary upload to the remote client?
5. What flag is hidden among the images?

The fourth question had only one submission attempt. The original cache file is not stored here.
