# Shipping Order Web App

A shipping company has stopped publishing information for some products. A supplied order page asks when one such order is due to arrive.

The original challenge instance was HTTPS only. Random automated brute force was prohibited; limited, educated fuzzing was allowed. The short-lived instance URL is omitted.

1. What programming language was the web app built with?
2. What is the flag associated with the restricted order?

The live instance and its order details are not stored here.
