# Ersatz Motel SQL Injection

A field agent needs the admin password for a motel system to reach an RFID code. The only accessible page in the challenge is the room reservation system, which is believed to have a SQL injection weakness.

The authorized scope was HTTPS only. Educated automated guesses were allowed, but blind automated brute force was prohibited. The short-lived instance URL is omitted.

1. Which form field can be used for SQL injection?
2. Which database product runs on the backend?
3. What is the target table name?
4. What is the target column name?
5. What is the admin user's password?

The live instance is not stored here.
