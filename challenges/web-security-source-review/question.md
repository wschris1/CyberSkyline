# Web security source review

## Question

The challenge application exposes its source code and warns that browser same-origin protections caused usability problems. Review the authorized application and answer:

| Question | Points |
| --- | ---: |
| What three-digit CWE weakness ID describes the vulnerability on `/login`? Multiple answers may be accepted. | 10 |
| What flag is set in the bot's cookie for `https://callback/`? | 25 |
| Which page displays unsanitized user input? Give the path. | 10 |
| What flag is displayed in `/admin`? | 55 |

The application may take up to a minute to boot. Keep the supplied source, session data, and response-bearing values private.
