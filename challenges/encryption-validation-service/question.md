# Encryption Validation Service

Liber8tion left a service that encrypts messages and validates whether ciphertexts came from a trusted user. The challenge supplies source code and an implementation, then asks the solver to interact with the authorized web service.

1. What symmetric block cipher does the server use?
2. What mode of operation is configured?
3. What exact word appears as a common issue in errors from the `/validate` route when testing different arbitrary payloads? The issue is unrelated to base64.
4. What flag is in the encrypted text?

The short-lived gateway URL and source files are not stored here.
