# Nginx Basic Authentication

An Nginx configuration and an `htpasswd` file are supplied. A web server is unexpectedly requiring a password for some content. Both passwords are five letters long. Recovering one account password is sufficient.

1. What is one account password?
2. What is the full filesystem path to the directory protected by passwords? Include the trailing slash.
3. What specific subdirectory is excluded from the password requirement?

The configuration and hash file are challenge evidence and are not stored in this repository.
