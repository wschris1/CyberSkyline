# DMZ terminal

## Question

Cyber Command found a Liber8tion server that appears to protect services from network scanning, but the protection may contain a bypass. The challenge host is named `target` and the supplied Kali terminal is the authorized vantage point.

Answer these questions from the challenge instance:

| Question | Points |
| --- | ---: |
| How many open TCP ports are accessible from the remote Kali host? | 10 |
| What software and version run on the highest open port? Use `software D.DD.D`. | 20 |
| What string bypasses that software's filtering controls? | 20 |
| After reaching the server from inside, what additional HTTP port below 10000 is open? | 20 |
| What flag is served by the service on that port? | 30 |

The instance is ephemeral. Obtain the terminal through the challenge platform and keep all response-bearing output, credentials, and flags outside this repository.
