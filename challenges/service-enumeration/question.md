# Service Enumeration

The challenge instance becomes unavailable once the challenge is completed. Enumerate the services on the server named `target` and answer the questions. Each question is worth 25 points.

1. What insecure shell service is exposed on `target`?
2. What is the full version string of the service running on the lowest TCP port?
3. One of the services reveals a hostname. What is the hostname (FQDN)?
4. One of the services responds with a flag. What is the flag?

Use the active challenge terminal. Addresses and response values are instance evidence and are not stored in this repository.
