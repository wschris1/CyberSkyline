# Password Hint Sheet

Jamie Pendergast's hint sheet and three Unix shadow files are supplied. The passwords written on the sheet do not work directly. The sheet contains reminders, and Jamie is interested in mathematics.

The reminders are `hail`, `6`, and `case`.

The passwords contain none of these characters: zero (`0`), one (`1`), `l`, `L`, or `|`.

1. What is the `jpendergast` password for `dev2`?
2. What is the `jpendergast` password for `dev6`?
3. What is the `jpendergast` password for `web1`?
4. What is the name of the conjecture used to generate the numbers for adjusting the passwords?

The sheet and shadow files are challenge evidence and are not stored in this repository.
