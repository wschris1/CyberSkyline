# Hercules Compliance Audit

The challenge instance becomes unavailable once the challenge is completed. Access has been gained to a machine belonging to a member of Liber8tion. Its hostname is `target`. A compliance scanner is available, but it is not running successfully.

1. What is the name of the guest-accessible SMB share? (10 points)
2. What is the SSH username found in the leaked credentials file? (10 points)
3. What is the full path to the compliance check profile hidden on your own machine? (10 points)
4. What is the SSH username used to run the compliance check? (20 points)
5. What is the password for that service account? (10 points)
6. What is the flag from the compliance-protected file? (40 points)

The scanner machine and remote target are distinct execution environments. Their credentials, profile path, and recovered outputs are private challenge evidence and are not stored here.
