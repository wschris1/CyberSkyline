# Censored Social Post Flag: how to solve

**Status:** Prompt recovered from a prior chat. No flag is verified in this guide.

1. Find the original post using the account's public archive, quoted post text, and date context. Preserve the source URL and image metadata privately.
2. Compare thumbnails, original media URLs, cached previews, and any accessible archived versions. Determine whether censorship was applied to the image data or only to a displayed overlay.
3. If the underlying image remains obscured, search for the same asset in earlier posts or official archives. Do not claim that image enhancement can recover pixels that were removed.
4. Validate the recovered text against an authentic source and the challenge's flag format. Keep the flag out of the public guide.

The old post may have moved or been removed, so source availability can limit reproduction.
